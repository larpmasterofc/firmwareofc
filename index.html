Firmware.

An open-source security multitool for the Espressif ESP32-S3, built on the Bruce project by pr3y. It consolidates wireless and hardware assessment tools behind a single on-device interface, localized in English, Portuguese, Spanish, French and German, and is released under the AGPL-3.0 with full source.

Open Source AGPL-3.0 ESP32-S3 5 boards EN / PT / ES / FR / DE Flash at 0x0 v1.0.0-beta Beta Browser demo
New in this release: hardware support now extends to the LilyGO T-Deck and T-Deck Plus, alongside the T-Display S3, T-Embed and T-Embed CC1101 — five boards in total. The binaries are new builds; the application code and feature set are unchanged from the previous release. This build adds two interface languages, French and German, so the language selector now offers five: English, Portuguese, Spanish, French and German. This release is 1.0.0-beta: the firmware now shows a one-time responsible-use notice on the first boot, and the info screen displays the version and build date.
Beta: no build has been tested on real hardware yet. Validation on the T-Embed is planned for Sunday. Flash at your own risk until then.

What it is

Firmware is a customized distribution of Bruce (pr3y), a comprehensive offensive-security toolkit for the ESP32 platform. This build modifies only the presentation layer — branding, default theme and interface language — while preserving the upstream codebase, its AGPL-3.0-or-later license and all original attribution. In accordance with the AGPL, the corresponding modified source is distributed with every release (firmware-source.zip).

The renamed identity reflects branding only and asserts no authorship over the underlying project. Attribution: "Based on Bruce by pr3y".

Firmware Zero (Flipper Zero plugin)

Firmware Zero is a companion app (.fap) for the Flipper Zero. The Flipper uses a different chip (STM32WB55), so the full ESP32 firmware does not run on it. This plugin brings the Firmware brand and menu to the Flipper for the radios it has built in.

What it uses

Sub-GHz (CC1101), Infrared, NFC, RFID 125 kHz, GPIO / ESP32 bridge.

What it can't do

WiFi and BLE: the Flipper has no native radio for them. Those need a LilyGO/ESP32 board.

First boot

Shows the same responsible-use notice as the firmware and this site.

Beta (v0.1): the branded menu, first-boot notice and navigation are done; the radio functions are still being wired to the hardware (they open a “module wiring in progress” screen for now).

Install

  1. Download firmware_zero.fap above.
  2. Copy it to your Flipper SD card under apps/Tools/ (or apps/), or use qFlipper.
  3. On the Flipper, open Apps and launch Firmware Zero.
This build targets the official Flipper firmware. If you run Momentum, Unleashed or RogueMaster, a matching build is needed to avoid API version errors.

Features

Toolset inherited from Bruce (menus/modules present in the code):

WiFi Bluetooth / BLE RF (sub-GHz) RFID Infrared (IR) NRF24 FM radio GPS LoRa Ethernet BadUSB Pwnagotchi Reverse Shell JS interpreter Files Clock Settings

Customizations in this firmware

  • UI in 5 languages: English, Portuguese, Spanish, French and German (selector under Settings → Language; English is the default).
  • Red theme as the default color.
  • Rebrand "Bruce" to "Firmware" (boot, home, info, BLE name, AP SSID, USB).
  • Cat mascot on the boot screen (replacing the shark).
  • Credit "Based on Bruce by pr3y" on the info screen.

No new attack features were added — the feature set is Bruce's.

How to flash

Each .bin is a combined image — flash it at 0x0. Select the file that matches your board.

esptool.py (command line)

# general example — replace <file> with the .bin for your board
esptool.py --chip esp32s3 write_flash 0x0 <file>

# T-Display S3
esptool.py --chip esp32s3 write_flash 0x0 firmware-t-display-s3.bin
# T-Embed
esptool.py --chip esp32s3 write_flash 0x0 firmware-lilygo-t-embed.bin
# T-Embed CC1101
esptool.py --chip esp32s3 write_flash 0x0 firmware-lilygo-t-embed-cc1101.bin
# T-Deck
esptool.py --chip esp32s3 write_flash 0x0 firmware-lilygo-t-deck.bin
# T-Deck Plus
esptool.py --chip esp32s3 write_flash 0x0 firmware-lilygo-t-deck-plus.bin

If you need to specify the port, add --port /dev/ttyACM0 (Linux) or --port COMx (Windows).

Web flasher (alternative)

  1. Connect the board via USB.
  2. Open esptool-js.
  3. Connect and select the serial port.
  4. Flash Address = 0x0, file = the .bin for your board.
  5. Click Program, wait, then reboot the board.
If the board does not enter flashing mode on its own: hold BOOT, tap RST, release BOOT and reconnect.

From source (PlatformIO)

pip install --user platformio
# use the environment matching your board
pio run -e lilygo-t-display-s3            # build
pio run -e lilygo-t-display-s3 -t upload  # flash

Technical notes

  • fastled/FastLED pinned to 3.10.3 (3.10.5 has a regression that conflicts with the board's FP macro).
  • No OTA: to update, rebuild and reflash.
  • Clean build (SUCCESS) and QEMU tests; not tested on real hardware — this release is beta, verify on your own board (T-Embed validation planned for Sunday).
  • On the T-Deck / T-Deck Plus, navigation uses the physical keyboard and the trackball.
